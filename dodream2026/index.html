우리 조의 작은 약속

  • 멋진 답보다 솔직하고 편한 답. 어려우면 “패스!”
  • 평가보다 호기심과 공감으로 들어요.
  • 연애·결혼 질문은 상상으로 답해도 좋아요. 경험이나 현재 관계를 밝힐 필요는 없어요.
  • 개인적인 이야기는 허락 없이 밖으로 옮기지 않아요.
🌱 조장님을 위한 진행 안내
  1. 가볍게 인사하기 — 이름과 좋아하는 간식을 나눠요.
  2. 공통 질문 하나 — 취향 질문에 돌아가며 답하고, 공감되면 손을 들어요.
  3. 내가 고른 질문 — 고른 사람이 먼저 답하고, 원하는 사람이 이어서 나눠요. 지목해서 답을 요구하지 않아요.
  4. 공통점 찾기 — 대화에서 발견한 공통점으로 조 이름이나 구호를 만들어 봐요.

전부 답하지 않아도 괜찮아요. 말할 기회는 골고루, 추가 질문은 “괜찮다면 조금 더 이야기해 줄래요?”
